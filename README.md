## نحوه استفاده

<div dir="rtl">

### دریافت کلید API
برای استفاده از اکثر این سرویس‌ها باید:
1. در وبسایت ارائه‌دهنده ثبت‌نام کنید
2. به بخش API Keys بروید
3. کلید API خود را ایجاد کنید
4. کلید را در پروژه خود استفاده کنید

### مثال استفاده (Python)

```python
import requests

# مثال برای XKiro
api_key = "YOUR_API_KEY"
headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json"
}

data = {
    "model": "gpt-3.5-turbo",
    "messages": [{"role": "user", "content": "Hello!"}]
}

response = requests.post(
    "https://api.xkiro.com/v1/chat/completions",
    headers=headers,
    json=data
)

print(response.json())
```

### نکات مهم
- ⚠️ همیشه محدودیت‌های RPM را رعایت کنید
- 🔐 کلیدهای API خود را محرمانه نگه دارید
- 📊 مصرف توکن‌های خود را رصد کنید
- 🔄 این لیست به طور مداوم بروزرسانی می‌شود
